# macOS-Utils

一组 macOS 工具，涵盖 TOTP 身份验证、订阅管理、截图处理、设备电量查询和 Terminal 会话配置处理。

## 功能概览

| 工具 | 用途 |
| --- | --- |
| Utilities · Authenticator | 管理 TOTP 账户，生成验证码，加密保存数据并支持导入导出。 |
| Utilities · SubTrack | 管理订阅、到期日和参考价格，展示到期提醒与续费预算。 |
| ScreenShotsWatcher | 监听截图，自动复制到剪贴板，并询问保留、移入废纸篓或永久删除。 |
| DeviceBattery | 通过命令行查询 HID 设备或蓝牙设备分部件电量。 |
| AppleTerminalFixer | 通过系统级启动服务，在开机时移除影响 Apple Terminal 会话行为的系统配置文件。 |

## 使用说明

- **Authenticator**：首次使用时设置解锁密码。本地账户数据加密保存；导出的文本包含明文密钥，应妥善保管。
- **SubTrack**：记录订阅的到期日、单次续费天数和参考价格。预算使用已填写的正数价格；官方价和第三方参考价均有效时取较低值。费用按币种分别汇总，到期提醒显示在应用内。
- **ScreenShotsWatcher**：当前按 `Screenshot` 文件名前缀和 `.png` 扩展名筛选截图，使用前应确认与系统截图命名一致。截图复制完成后，可选择保留、移入废纸篓或永久删除；设置功能会修改系统截图偏好。
- **DeviceBattery**：选择 `HID` 或 `SP` 查询模式并指定设备名称。`SP` 模式使用 `-1`、`0`、`1` 分别选择左耳、充电盒和右耳；查询结果取决于系统提供的电量信息。
- **AppleTerminalFixer**：安装过程需要管理员权限，并会配置开机执行的系统文件删除操作；使用前应确认这一行为符合需要。
